# 나만의 학회 프로필

압축을 푼 `student_project` 폴더를 VS Code의 **파일 → 폴더 열기**로 여세요. 파일 탐색기에서 `index.html`을 브라우저로 열고 수정할 때마다 저장 후 새로고침하세요. 서버나 패키지 설치는 필요 없습니다.

이름, 전공과 소개는 모두 예시이며 실제 개인정보를 입력할 필요가 없습니다. GitHub 링크도 예시입니다. 강사의 안내에 따라 첫 커밋 후 `index.html`의 TODO 1에서 제목 또는 소개를 수정하고, `feature/profile` 브랜치에서 TODO 2 위치에 새 관심 영역을 추가합니다. `style.css`를 바꾸면 색상도 바꿀 수 있습니다.

Git 실습 명령은 VS Code의 **터미널 → 새 터미널**에서 이 폴더를 연 상태로 실행합니다. GitHub에 공개 저장소를 만들 때는 개인 정보와 비밀키를 올리지 마세요.
